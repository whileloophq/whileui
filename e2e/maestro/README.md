# Native flows

Maestro drives a built app through the **platform accessibility hierarchy** — the same
tree VoiceOver and TalkBack read. That is the whole reason this layer exists here, and it
is why a flow belongs here only when no cheaper layer can see the defect.

What the layers below cannot prove, from `PLAN.md` > Evidence model:

- **Accessibility containment — on iOS only.** `isAccessibilityElement` collapses
  descendants out of the accessibility tree, so a button inside an over-accessible panel
  simply is not there. Confirmed on a simulator: with the fix, the tree holds the dialog's
  title, description, Cancel and Delete; without it, only the title.
  **Android does not behave this way** — `accessible` groups children for TalkBack but
  leaves every node in the UIAutomator tree, so the same flow passes there either way.
  **Run the iOS flow when you touch an overlay container.** Android will not save you.
- **The OS keyboard** — `KeyboardAwareScreen` picks a `KeyboardAvoidingView` behaviour per
  platform, and nothing below this can observe the result.
- **Android hardware back** dismissing the topmost overlay.
- **`RefreshControl`**, which React Native Web does not implement at all.

## Running

Needs a built app on a running simulator or emulator — these run against artifacts, not
Metro.

```bash
cd apps/showcase && bunx expo run:android   # or run:ios
maestro test e2e/maestro
```

`bun run test:native` does both steps.

## Requirements

- **Android**: SDK, an AVD, JDK 17+.
- **iOS**: **Xcode ≥ 16.1** — React Native 0.86 refuses `pod install` below that
  (`react-native/scripts/cocoapods/helpers.rb`, `min_xcode_version_supported`).

Native projects are generated by `expo prebuild` and gitignored; the showcase stays a
managed Expo app.

## Writing a flow

Assert what a user or a screen reader can perceive — visible text, labels, reachability.
A flow that passes whether or not the fix is present is worse than no flow: it reports
coverage that does not exist. Check by reverting the fix and watching it fail.
