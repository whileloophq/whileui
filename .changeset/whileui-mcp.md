First release. An MCP server that answers from the catalog inside the installed
`@thewhileloop/whileui`: `list_components`, `get_component_docs`, `get_theme_tokens` and
`get_guide`. Run it from a project that has WhileUI installed:
`claude mcp add whileui -- npx -y @thewhileloop/whileui-mcp`.
